# 量潮标准范畴

## 资产构成

第二大脑由 18 种标准资产（两个九宫格）加 Context（工作语境）和 Archive（工作归档）两种不占格资产构成，按陈述型记忆和程序型记忆两大九宫格体系组织。

Context 是所有九宫格资产的默认入口，Archive 是过时资产的备份出口，两者不占九宫格位置。资产类型定义是资产治理的基本契约，所有仓库命名、目录结构、文档格式均以此为依据。

## 工作记忆

Context 是九宫格的默认入口：用户从日常工作中感知到模式或疑问后，进入 Context 记录观察与约束，作为后续格子的共同起点。

## 陈述型记忆

陈述型记忆回答组织「知道什么」的问题，按类型维度（事件类、语义类、自我类）与时间维度（过去、现在、未来）交织为九宫格。

类型维度：事件类记录组织的行动与计划；语义类沉淀组织的认知与参考；自我类呈现组织的身份与叙事。

时间维度：过去为已履行的契约；现在为正在履行的契约；未来为将要履行的契约。

| 位置 | 事件类 | 语义类 | 自我类 |
|:----|:-------|:-------|:-------|
| 过去 | Report 工作报告 | Library 工作参考 | History 工作历史 |
| 现在 | Journal 工作日志 | Profile 工作档案 | Brochure 宣传册 |
| 未来 | Roadmap 路线图 | Insight 工作洞察 | Intention 工作意图 |

## 程序型记忆

程序型记忆回答组织「怎么做事」的问题，按约束力层次（宪法、法律、法理）与消费对象（人类友好、AI 友好、规则引擎友好）交织为九宫格。

约束力层次：宪法为最高约束力，规定基本原则与权责划分；法律为中等约束力，系统性程序规范；法理为低约束力，基本原理与方法论。

消费对象：人类友好强调可读性与启发性；AI 友好强调结构化与可解析性；规则引擎友好强调可执行性。

| 位置 | 规则 | 建模 | 应用 |
|:----|:---------|:-------|:-------------|
| 宪法 | Bylaw 工作章程 | Specification 工程标准 | Toolkit 工具箱 |
| 法律 | Handbook 工作手册 | Gallery 工作案例 | Platform 平台 |
| 法理 | Tutorial 工作教程 | Essay 工作札记 | Example 示例程序 |

### 工作手册与工作案例

程序型记忆九宫格里，Handbook（工作手册）与 Gallery（工作案例）同处法律层，约束力相当，实务中最易混同。二者的分界不在题材，在粒度：

- 工作手册收一类情况的判断——可跨实例复用的判定尺子。
- 工作案例收一次具体的工作流程——一次工作的时间、参与人与做法结果。

由此得一条可操作的判据：同一份内容，换一个实例仍然成立，归工作手册；只对那一次成立、离开那次的时间与参与人便失去意义，归工作案例。两边不并存——从一次工作里提炼出的尺子进手册，那次工作的过程与结果进案例，各归其位。

## 遗忘记忆

Archive 用于备份两类九宫格中所有格子的过时文件，确保组织知识的持久化存储与可追溯性。
